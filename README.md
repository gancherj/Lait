# Lait

This repository contains the Lait teaching language and its textbook.

## Running Lait code 

See the [starter repo](https://github.com/gancherj/Lait-Starter) for instructions on how to run Lait code.


## Viewing the textbook

The textbook for Lait will
be hosted soon.  
It is a work in progress.

## Building the textbook

Navigate to the `Textbook` directory and run:
```
npm install @leandown/mdbook
mdbook serve
```

This will give you a local server to view the textbook.
